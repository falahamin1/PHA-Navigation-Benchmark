# Nav-Benchmark — Staged Build Roadmap

The build is staged. Implement only the current gate, write the specified
tests for it, and stop for review before moving to the next gate. Once a gate
has passed review, do not modify that layer without explicitly flagging the
change and why.

**Locked project conventions** (see DESIGN.md / SPEC.md for the "what"/"why"):
- Env API: `gymnasium`
- Utilities (PPL geometry helpers, stats layer): local `Nav-Benchmark/utils/`, not repo-shared
- Config: inline `HP = {...}` dict per training script, matching every other benchmark in this repo
- Reusable starting points from the existing repo (adapt, don't copy blindly):
  - `Rush-hour-git/DeepSetRL.py` — φ/ρ DeepSets pattern (LayerNorm variant)
  - `Rush-hour-git/PPOBuffer.py`, `Rush-hour-git/checkpoint_utils.py` — PPO+GAE buffer and resumable checkpointing
  - `Rush-hour-git/GraphNNRL.py` — hand-rolled GCN layer pattern (no PyG/DGL used anywhere in this repo)
  - `Rush-hour-git/CNNRL.py`, `Rush-hour-git/MLPRL.py` — CNN/flat-MLP baselines
  - `water_level_env.py` (`_poly_to_constraints`, `_poly_to_vertices`, `_build_constraint_graph`) — PPL H-rep/V-rep extraction pattern; note this repo has never implemented true facet-adjacency (only shared-vertex adjacency), so Gate 4's PPL adjacency work is genuinely new

---

## Gate 1 — Dynamics core
**Builds:** `Nav-Benchmark/dynamics/` — 4D Euler integrator over state (x₁,x₂,v₁,v₂); the 4×4 A matrix (config-selectable C2E2 vs. original Fehnker–Ivančić coupling); B and the 8 compass direction vectors, derived by matching the four verified C2E2 per-mode drift equations (SPEC.md §2.1).
**Tests:** integrate all 4 verified C2E2 modes and compare against the closed-form v̇ equations in SPEC.md; confirm a trajectory under each of the 8 directions converges toward that direction's steady-state velocity.
**STOP — review before proceeding to Gate 2.**

## Gate 2 — EASY partition + mode switching
**Builds:** 5×5 unit-box grid over [0,5]×[0,5]; PPL point-in-cell containment; boundary-crossing detection and mode switch logic.
**Tests:** a fixed hand-picked direction map drives a trajectory from the start region to a chosen goal cell without passing through hazard cells; no missed or duplicated mode-switch events across a full episode.
**STOP — review before proceeding to Gate 3.**

## Gate 3 — Gym env + first encoder
**Builds:** `gymnasium`-style env wrapping Gates 1–2 with the 8-direction discrete action space and the full reward (step penalty, potential-based shaping, hazard/goal absorbing terms); H-Rep DeepSet encoder; PPO+GAE training loop.
**Tests:** env API compliance (reset/step contracts, reward within expected bounds, correct absorbing termination on goal/hazard/horizon); trained agent solve rate on EASY exceeds a defined threshold across held-out seeds.
**STOP — review before proceeding to Gate 4.**

## Gate 4 — MEDIUM/HARD partitions + remaining 5 encoders
**Builds:** procedural mixed-convex (MEDIUM) and irregular-convex (HARD) partition generators, seeded and reproducible; PPL facet-adjacency computation (new geometry primitive for this repo); cell-adjacency graph construction with edge features; V-Rep DeepSet, relational-feature DeepSet, GNN, CNN, and MLP encoders.
**Tests:** generated partitions are valid (all cells convex, facet-count distribution matches SPEC.md §2.2 ranges); adjacency graph correctness verified on hand-constructed small partitions; one forward pass per encoder produces the correct output shape.
**STOP — review before proceeding to Gate 5.**

## Gate 5 — Instance pools
**Builds:** per-tier instance-pool generation (partition seed, goal/hazard placement, initial velocity sign randomization); BFS solvability filter on the cell-adjacency graph; train/test split, target ≥120 held-out test instances per tier.
**Tests:** zero unsolvable instances in any generated pool; train/test sets are disjoint; regenerating with the same seed reproduces the same pool.
**STOP — review before proceeding to Gate 6.**

## Gate 6 — Stats layer
**Builds:** `Nav-Benchmark/utils/` — Wilson confidence intervals, McNemar's test, Wilcoxon signed-rank test, Holm–Bonferroni correction, rliable IQM + stratified bootstrap CIs, BFS/Dijkstra shortest-route oracle for optimality-gap comparison. All genuinely new to this repo (no prior benchmark has any of this).
**Tests:** each statistic checked against a hand-computed or scipy-cross-checked toy case with known expected output.
**STOP — review before proceeding to Gate 7.**

## Gate 7 — ν-vs-advantage sweep
**Builds:** incidence-variability index ν (entropy/variance of per-cell facet-count or adjacency-degree distribution) computed per tier; full 6-encoder × 3-tier × 5–10-seed training run using the Gate 6 stats layer; headline plot of (GNN reward − best DeepSet reward) vs. ν.
**Tests:** ν(EASY) ≈ 0 as expected; full sweep produces per-tier, per-encoder solve-rate/reward/optimality-gap tables with CIs.
**Success criteria (DESIGN.md §1.8):** monotone ν-vs-advantage curve, GNN > DeepSet at HARD with non-overlapping CIs, GNN ≈ DeepSet at EASY — or, as an equally valid outcome, GNN ties the relational-feature DeepSet (encoder #5) even at HARD, reported honestly as "relational features are what matter."
